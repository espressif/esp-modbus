# Modbus Get Started Example

Introductory example for the Esp-Modbus stack. Start here if you are new to Modbus on ESP-IDF.

## Examples

| Example | Description |
| ------- | ----------- |
| [basic_master](basic_master/) | Modbus master — initialize the controller, set up a data dictionary, and perform read/write requests |


Both examples support **UART (RTU/ASCII)** and **TCP** communication.

## Quick Start

1. Open the README in each example folder for build and configuration steps.
2. Use the **same communication mode** on both sides (RTU, ASCII, or TCP).
3. Flash the **slave first**, then the **master**.

For API details, see the [Esp-Modbus documentation](https://docs.espressif.com/projects/esp-modbus/en/main/esp32/index.html).
